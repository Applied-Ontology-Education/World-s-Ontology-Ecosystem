Generate an OWL ontology representing a vehicle-maintenance problem-reporting scenario.

The ontology should represent a vehicle, a reported vehicle problem, an observation of the problem, a maintenance problem report, a problem code, a maintenance activity performed in response to the problem, and a technician involved in the maintenance activity.

The ontology should support questions such as:
What problem was reported for a particular vehicle?
What observation led to the problem report?
What problem code was assigned?
What maintenance activity was performed in response?
Which technician participated in the maintenance activity?
What information in the problem report is about the observed vehicle condition?

Use OWL 2 and serialize the ontology in Turtle so that it can be opened in Protégé.
Include:
classes;
object properties;
data properties where appropriate;
named individuals representing one example maintenance case;
textual definitions for classes and relations;
appropriate subclass, domain, range, and restriction axioms.

Use Basic Formal Ontology (BFO) as the upper-ontology framework where appropriate.
Distinguish classes from named individuals and literal values.

Do not provide an explanation outside the ontology. Return the complete Turtle serialization.
